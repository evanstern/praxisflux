A port is one fixed plug shape. An adapter is whatever you wire into that plug — GitHub today, Azure DevOps today, a third host later, without changing the plug itself. Click either adapter box below for its key functions and real file.

: ADAPTERS = {"github": GitHubAdapter, "azure-devops": AzureDevOpsAdapter}, selected by identity.py's resolved provider. See for the full action list.

Known limitation

The compensating control is detection, not prevention: by the time the independent read disagrees, nothing has been corrected, only stopped before (or flagged after) a write.
