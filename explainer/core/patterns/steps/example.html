Stage flow: opening a PR

Click any step for the detail that doesn't fit inline.

  1. pr-review → core.py
    Push the branch, then call open_pr.
  2. core.py → GitHubAdapter
    Check for an existing PR on the source branch — none found.
  3. GitHubAdapter → api.github.com
    Create the PR on the host.
  4. core.py → pr-review
    One VerdictEnvelope back on stdout, exit 0.
