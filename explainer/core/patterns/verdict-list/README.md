# verdict-list

Numbered short answers.

## When to use

- A "Start here" / short-answer page type's numbered list of direct
  conclusions, each short enough to read in one glance.

## When not

- A step-by-step procedure with its own detail panels — use `steps`
  (Phase 2b).
- A grade read per option — use `table`'s grade cells, or `matrix` for a
  two-axis verdict read.

## Markup contract

```html
<ol class="ex-verdict-list">
  <li><p>First conclusion.</p></li>
  <li><p>Second conclusion.</p></li>
</ol>
```

- Root class `ex-verdict-list` goes on the `<ol>` (or `<ul>` — the numbering is
  a CSS counter, not the list's native `start`/type).
- Each `<li>` is one entry; the number badge is generated by CSS
  (`counter-increment`), so authors never write the number themselves.
- No JS; `verdict-list.js` is not shipped.

## Tokens used

`--ex-accent`, `--ex-accent-ink`.
