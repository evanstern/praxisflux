# Architecture Site — components

**What this page answers:** Introduce each major component: its responsibility, its interfaces, and what depends on it.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `cards`, `table`.
**Diagrams that fit:** none suggested.

**House style:** see `references/house-style.md` for the full text of
`tables-over-prose-lists`, `cite-every-claim`, `info-for-detail-in-tight-space`.

**What to avoid:** Don't describe components in a prose list — use cards or a table so they're scannable.
