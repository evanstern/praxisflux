# Architecture Site — scenario-walkthrough

**What this page answers:** Walk one real request or event through the system end to end.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `scenario`, `panel`.
**Diagrams that fit:** `sequence`.

**House style:** see `references/house-style.md` for the full text of
`real-vs-illustrative`, `hide-depth-behind-interaction`, `info-for-steps`.

**What to avoid:** Don't describe a scenario in the abstract — walk one concrete call through to its result.
