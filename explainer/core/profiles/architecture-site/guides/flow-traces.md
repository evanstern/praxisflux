# Architecture Site — flow-traces

**What this page answers:** Trace a control or data flow across several components in sequence.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `scenario`.
**Diagrams that fit:** `sequence`.

**House style:** see `references/house-style.md` for the full text of
`svg-diagrams-not-ascii`, `diagram-text-budget`, `one-color-coded-diagram`,
`info-for-steps`.

**What to avoid:** Don't skip steps for brevity — a flow trace that elides a hop is worse than a shorter one that doesn't.
