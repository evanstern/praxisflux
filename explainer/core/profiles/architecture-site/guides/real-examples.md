# Architecture Site — real-examples

**What this page answers:** Show real, generator-sourced examples of the system's actual inputs and outputs.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `code`, `annotated-json`.
**Diagrams that fit:** none suggested.

**House style:** see `references/house-style.md` for the full text of
`real-vs-illustrative`, `legible-inline-code`, `code-font-scroll`,
`info-for-evidence`.

**What to avoid:** Never hand-type an example tagged Real — if it isn't from an approved generator, tag it Illustrative instead.
