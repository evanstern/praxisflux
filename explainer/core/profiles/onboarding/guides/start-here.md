# Onboarding — start-here

**What this page answers:** Give a reader (live or async) a one-screen kickoff: what this artifact is, who should read which page, and how to ask questions.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `callout`, `presenter`.
**Diagrams that fit:** none suggested.

**House style:** see `references/house-style.md` for the full text of
`kickoff-page`, `callouts-for-asides`.

**What to avoid:** Don't bury the kickoff in detail — it points the reader onward, it doesn't replace the pages it points to.
