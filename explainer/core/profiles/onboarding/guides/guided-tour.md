# Onboarding — guided-tour

**What this page answers:** Walk the real codebase in a sensible order, pointing out what matters and what to skip.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `file-map`, `panel`.
**Diagrams that fit:** `swimlanes`.

**House style:** see `references/house-style.md` for the full text of
`hide-depth-behind-interaction`, `no-internal-codes`, `info-for-steps`.

**What to avoid:** Don't walk every file — pick the ones that matter and say why the rest can wait.
