# Decision Briefing — case-study-evidence

**What this page answers:** Back the recommendation with real case-study data, generated from the source material.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `cards`, `stats`.
**Diagrams that fit:** `bar`.

**House style:** see `references/house-style.md` for the full text of
`charts-have-data-tables`, `real-vs-illustrative`.

**What to avoid:** Don't present a chart without its data table — a reader who needs exact values must not have to guess from pixels.
