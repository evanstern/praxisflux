# Decision Briefing — open-questions

**What this page answers:** List what's still unresolved, each with an explicit confidence level.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `table`, `callout`.
**Diagrams that fit:** none suggested.

**House style:** see `references/house-style.md` for the full text of
`cite-every-claim`, `single-sentence-bullets`.

**What to avoid:** Don't list a question without a confidence level — an unscored open question reads as settled.
