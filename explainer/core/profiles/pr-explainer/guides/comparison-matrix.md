# PR Explainer — comparison-matrix

**What this page answers:** Compare old vs. new behavior (or option A vs. option B) cell by cell instead of in prose.

**Facts it needs:** every claim on this page must trace to an id in
`facts.json` (or, for a generated page, to the generator's own output) —
never state something the fact-gatherer didn't record.

**Patterns that fit:** `matrix`, `legend`.
**Diagrams that fit:** none suggested.

**House style:** see `references/house-style.md` for the full text of
`mapped-matrices`, `tables-over-prose-lists`.

**What to avoid:** Don't describe a mapping in prose — a matrix or table reads faster and verifies easier.
